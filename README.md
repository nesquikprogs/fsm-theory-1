# Лабораторные работы по теории автоматов и формальным моделям вычислений

Данный репозиторий содержит набор лабораторных работ, посвящённых изучению **конечных автоматов, клеточных автоматов и машины Тьюринга**.  
Работы направлены на практическое освоение формальных моделей вычислений, алгоритмов их обработки и визуализации.
