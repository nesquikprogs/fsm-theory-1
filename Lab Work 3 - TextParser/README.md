# Лабораторная работа: Конечный автомат для удаления комментариев из исходного кода

## Суть программы

- Программа реализует **конечный автомат**, предназначенный для обработки исходного кода и удаления из него комментариев.
- Автомат последовательно читает **каждый символ входного файла**.
- В зависимости от текущего состояния и прочитанного символа выполняется переход в новое состояние.
- В результате формируется **выходной файл**, содержащий исходный код **без комментариев**, при этом:
  - программный код сохраняется;
  - строковые и символьные литералы сохраняются;
  - все комментарии полностью удаляются.

---

## Состояния конечного автомата

Автомат содержит **5 состояний**:

1. **Обычный код**  
   Основное состояние, в котором анализируется код и определяется начало комментариев или литералов.

2. **Однострочный комментарий (`//`)**  
   Все символы игнорируются до конца строки.

3. **Многострочный комментарий (`/* ... */`)**  
   Все символы игнорируются до обнаружения закрывающей последовательности `*/`.

4. **Строковый литерал (`"..."`)**  
   Все символы сохраняются, включая те, которые внешне похожи на комментарии.

5. **Символьный литерал (`'...'`)**  
   Все символы сохраняются, включая экранированные и специальные символы.

---

## Принцип работы автомата

- Автомат **начинает работу в состоянии «Обычный код»**.
- Для каждого символа входного файла:
  - анализируется текущее состояние;
  - проверяется символ или их последовательность;
  - определяется переход в новое состояние.
- В зависимости от состояния:
  - символ **записывается** в выходной файл;
  - или **игнорируется** (если он относится к комментарию).

---

## Правила переходов (обобщённо)

- Из состояния **Обычный код**:
  - `//` → переход в **Однострочный комментарий**
  - `/*` → переход в **Многострочный комментарий**
  - `"` → переход в **Строковый литерал**
  - `'` → переход в **Символьный литерал**

- Из состояния **Однострочный комментарий**:
  - `\n` → возврат в **Обычный код**

- Из состояния **Многострочный комментарий**:
  - `*/` → возврат в **Обычный код**

- Из состояния **Строковый литерал**:
  - `"` (неэкранированная) → возврат в **Обычный код**

- Из состояния **Символьный литерал**:
  - `'` (неэкранированная) → возврат в **Обычный код**

---
